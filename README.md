# Brasil — Pesquisa Eleitoral TSE 2026

Painel estático e responsivo para acompanhar a trajetória das pesquisas eleitorais nacionais de primeiro turno para a Presidência da República em 2026.

## Recursos

- gráfico temporal por levantamento;
- média mensal opcional;
- fotos públicas dos candidatos;
- filtros por candidato;
- detalhes de instituto, campo, amostra, margem, registro e fonte;
- layout responsivo para celular e computador;
- configuração pronta para Vercel.

## Desenvolvimento local

Abra `index.html` diretamente no navegador ou use um servidor estático:

```bash
npx serve .
```

## Publicação

O projeto é estático e pode ser importado diretamente no Vercel sem comando de build.

## Nota metodológica

O PesqEle/TSE registra pesquisas e documentos, mas os percentuais por candidato precisam ser conferidos nos relatórios ou publicações de cada instituto. A base deste projeto deve ser revisada e atualizada continuamente.
